01 what each module does

Modules are numbered top to bottom; use the arrows to change the order. Each Buttons module is three pads, numbered in this order. identify flashes a Buttons module's lights or a Pixels strip, and pressing, turning or waving at a module lights up its card, so you can tell which is which.

02 live from the bus

      03 setting up modules

      A new module answers at its factory address. Add new modules one at a time to the end of the chain: each one is given the next free address, then has to be unplugged and plugged back in once to take it. The banner at the top says when.

      For a module that won't show up in the chain: it may hold an address another module already has. Turn this on, unplug the chain from the UNO Q and plug only that module into the UNO Q's Qwiic socket. It shows up below whatever address it holds. give free address sets it up there and then (unplug it and plug it back in once to make it take effect), or reset sends it back to its factory address so the chain sets it up when you add it. Turn this off again before reconnecting the chain.

        forget old addresses frees every address handed out so far except those of the modules in the chain (as it was the last time it was plugged in), so they can be given out again.

        Sends every connected Buttons, Knob and Pixels module back to its factory address, and forgets the addresses handed out so far. Then plug them back in one at a time.
